# Day 83 — Personal Portfolio

An original portfolio website built with HTML, CSS and JavaScript.

## Files

- `index.html` — page structure and content
- `style.css` — layout, typography, responsive design and animations
- `script.js` — mobile navigation, scroll reveal and cursor interaction

## Run locally

Open `index.html` in your browser, or use the Live Server extension in VS Code.
